Appearance

Shop

This name, address, phone and logo appear on cashier receipts, invoices, purchase-order factures and barcode labels.

Printers

Cashier receipts and 80mm tickets print automatically to the receipt printer; A4 factures and invoices print to the A4 printer; barcode labels print to the label printer. Choose "Default" to pick a printer in the dialog each time.

Barcode Scanner

Most USB/Bluetooth barcode scanners type the code then press Enter - if yours does, leave this checked and scanning into the Cashier search box will add the item automatically.

Pricing & Margins

When adding a product with a wholesale price but no sale price, this default margin % will be used to auto-calculate the sale price (sale = wholesale x (1 + margin/100)). Leave empty to disable.

Weighing Scale

For supermarket items sold by weight (produce, meat). Cashier products marked "By weight (kg)" ask for a weight; this sets how a scale feeds it in.

VAT (TVA)

When enabled, the receipt shows a VAT breakdown (amount without VAT, rate and VAT amount) for information only. It does not change the sale total. In Algeria the standard rate is 19% and the reduced rate is 9%.

Print preview & diagnostics

See exactly what each document looks like before you print - no paper needed. Use this to check receipts, invoices, factures and labels on any screen.
